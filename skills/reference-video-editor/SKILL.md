# Reference Video Editor

Translate a reference into an original, executable edit. Preserve the user's message and supplied footage while borrowing general techniques such as pacing, caption hierarchy, framing, or transitions. Do not promise a rendered video when only a transcript or editing plan can be produced.

## Select the deliverable and inspect inputs

Confirm the intended audience, destination, approximate duration, aspect ratio, and requested output: critique, edit decision list, editable project, preview, or final export. Inspect supplied material first and ask only for missing decisions that affect the edit. Respect an explicitly chosen editor or format.

Inventory source clips with stable IDs, file names, duration, dimensions, frame rate, orientation, audio tracks, and available transcript. Identify which reference videos can actually be viewed. A transcript supports language and approximate structure; it does not reveal camera framing, facial delivery, color, or visual timing. Name these limitations rather than inventing observations.

Check available editing, transcription, audio, and rendering tools before choosing the method. Use current official documentation when a command or integration depends on uncertain behavior. Do not require a particular vendor or upload footage merely because a source workflow mentions it. Preserve the originals and use separate output paths for authorized edits.

## Extract a practical style profile

Study a small, relevant sample of references. Describe observable choices and attach timecodes where useful:

- Format and framing: orientation, subject placement, crop, safe areas.
- Rhythm: approximate shot lengths, pauses, cut triggers, hook and ending.
- Text: caption density, hierarchy, placement, contrast, emphasis.
- Visuals: B-roll purpose, transitions, color treatment, zoom restraint.
- Audio: speech clarity, music role, sound effects, silence.

Separate measured observations, estimates, and creative recommendations. Explain which techniques serve the requested audience and which should be omitted. Use a compact profile that another editor can execute; avoid claiming a font, lens, exact grade, or proprietary preset from appearance alone. Do not reproduce distinctive third-party footage, graphics, or music without appropriate rights.

## Build the edit before rendering

Use the source transcript and footage to identify the promise, essential explanation, proof, and final action. Remove repetition and dead time while preserving meaning, necessary qualifications, and natural delivery. Avoid cuts that create a false statement or misleading demonstration.

Create an edit decision list with explicit source timecodes, not just instructions such as “make it faster”:

    Output segment / source clip ID / source in–out:
    Keep, cut, move, or replace:
    Spoken content and purpose:
    Picture, crop, or B-roll:
    Caption/on-screen text:
    Audio or transition:
    Reason / required asset / unresolved issue:

Clarify whether timecodes refer to source media or the output timeline. Identify estimates requiring frame-level confirmation. Use B-roll to clarify a point or show evidence, not to imply an event or result that was not captured. Preserve actual product appearance and property features. Mark missing material explicitly; do not silently substitute generated evidence.

## Render within the authorized scope

If tools and media are available, implement the requested edit and produce a preview. Otherwise deliver the style profile, EDL, revised script, caption draft, and precise editor handoff; label this as an edit plan.

Use actual clip durations and the selected timeline frame rate for transition math. Define the intended visual and narration endpoint. When narration overruns, revise wording, retime footage, or extend suitable material; do not silently cut the final sentence or CTA. When narration ends early, preserve the intended visual ending with deliberate silence or music. A command that ends output at the shortest stream is not a substitute for this decision. Review caption synchronization after timeline changes.

Normalize media only as needed for the editor or export. Preserve aspect ratio unless the crop is deliberate and checked. Keep speech intelligible, avoid clipping, and use destination-appropriate loudness and delivery specifications rather than claiming a universal technical preset.

## Verify and hand over

Inspect the actual render: beginning and ending, cut points, black/frozen frames, audio continuity, synchronization, caption spelling/placement, mobile readability, and important crops. Check exported dimensions, duration, audio, and playback. Use a focused sample for interim work and a complete review for final delivery. State any material parts not inspected.

Return the artifact path or usable preview, editable project when requested and available, style profile/EDL, export settings, and remaining issues. Distinguish planned edits, completed edits, rendered output, and reviewed output. Honor existing authorization without restarting approval; an editing request does not independently authorize publication or distribution.
